# Automotive Manufacturing Operations and Customer Service

## Overview

This multi-agent network demonstrates an automotive manufacturing and customer service system designed for companies like Volkswagen, Ford, or BMW. It showcases how specialized AI agents can collaborate to handle complex manufacturing operations, supply chain management, dealership support, and customer service inquiries across the automotive value chain.

The system manages everything from production line optimization and quality control to vehicle service scheduling and customer inquiries, providing a comprehensive solution for modern automotive operations.

## Use Case

Modern automotive manufacturers like Volkswagen, Ford, and BMW face multifaceted challenges:

- **Manufacturing Operations**: Coordinating complex production lines across multiple facilities globally
- **Supply Chain Complexity**: Managing thousands of parts suppliers and just-in-time inventory
- **Quality Assurance**: Ensuring consistent quality standards across vehicles and components
- **Dealership Network**: Supporting hundreds or thousands of dealerships with technical and operational guidance
- **Customer Service**: Handling warranty claims, recalls, service appointments, and general inquiries
- **Regulatory Compliance**: Navigating emissions standards, safety regulations, and regional requirements

This agent network addresses these challenges by routing requests to specialized agents with domain expertise in each area.

### Agent Descriptions

#### **Automotive_Operations_Coordinator** (Frontman Agent)
The main orchestrator that receives all incoming requests and intelligently routes them to the appropriate specialized agent or agent network. It understands the context of automotive operations and ensures queries are handled by the most qualified agent.

**Key Capabilities:**
- Intelligent query classification and routing
- Multi-agent coordination for complex requests
- Context preservation across agent handoffs
- Priority escalation for critical issues (safety recalls, production line stoppages)

---

#### **Manufacturing_Operations_Agent**
Handles all aspects of automotive production, from planning to execution and optimization.

**Sub-Agents:**

**Production_Planning_Specialist**
- Creates and optimizes production schedules
- Balances capacity across multiple facilities
- Manages model changeovers and variant production
- Handles production line rebalancing requests

**Quality_Control_Agent**
- Monitors quality metrics across production lines
- Investigates defect patterns and root causes
- Coordinates corrective actions
- Tracks quality KPIs (First Time Through rate, defects per million)

**Factory_Efficiency_Optimizer**
- Analyzes Overall Equipment Effectiveness (OEE)
- Identifies bottlenecks in production processes
- Recommends efficiency improvements
- Monitors downtime and maintenance schedules

**Example Queries:**
- "What's the current production status at our Wolfsburg plant?"
- "We're experiencing a quality issue with transmission assemblies on the F-150 line"
- "Can we increase production of the ID.4 model next quarter?"
- "What's causing the bottleneck on Assembly Line 3?"

---

#### **Supply_Chain_Management_Agent**
Manages the complex network of suppliers, parts, and logistics that keep automotive manufacturing running.

**Sub-Agents:**

**Parts_Inventory_Specialist**
- Tracks inventory levels across warehouses
- Manages just-in-time (JIT) delivery schedules
- Identifies potential shortages before they impact production
- Coordinates emergency parts procurement

**Supplier_Relations_Agent**
- Maintains supplier quality ratings
- Handles supplier communications and escalations
- Manages supplier onboarding and qualification
- Tracks supplier delivery performance

**Logistics_Coordinator**
- Optimizes inbound and outbound logistics
- Coordinates vehicle distribution to dealerships
- Manages cross-border shipping and customs
- Tracks shipment status and resolves delays

**Example Queries:**
- "Do we have sufficient semiconductor inventory for next month's production?"
- "Which suppliers are experiencing delivery delays?"
- "What's the delivery timeline for ID.4 vehicles to California dealerships?"
- "We need to expedite battery shipments to the Dearborn plant"

---

#### **Dealership_Support_Agent**
Provides comprehensive support to the dealer network, enabling them to serve customers effectively.

**Sub-Agents:**

**Technical_Service_Advisor**
- Provides technical guidance for complex repairs
- Interprets diagnostic codes and symptoms
- Recommends repair procedures and parts
- Assists with TSBs (Technical Service Bulletins)

**Sales_Operations_Support**
- Answers product specification questions
- Provides pricing and incentive information
- Handles allocation and ordering support
- Assists with inventory management

**Warranty_Claims_Processor**
- Reviews and approves warranty claims
- Identifies warranty fraud patterns

**Example Queries:**

- "What incentives are available on the F-150 Lightning this month?"

### Example Code Tools

```python
class ManufacturingDataTool(CodedTool):
    """Retrieves real-time manufacturing data from MES"""
    
    async def execute_async(self, args: dict, sly_data: dict) -> str:
        plant = args.get("plant_code")
        metric = args.get("metric_type")
        
        # Query manufacturing system
        data = await query_mes_system(plant, metric)
        
        return format_manufacturing_report(data)

class VehicleRecallLookupTool(CodedTool):
    """Checks if a VIN is affected by recalls"""
    
    async def execute_async(self, args: dict, sly_data: dict) -> str:
        vin = args.get("vin")
        
        # Query NHTSA and internal recall database
        recalls = await check_recall_status(vin)
        
        if recalls:
            return format_recall_information(recalls)
        else:
            return "No open recalls found for this vehicle."

class PartAvailabilityTool(CodedTool):
    """Checks parts inventory across warehouse network"""
    
    async def execute_async(self, args: dict, sly_data: dict) -> str:
        part_number = args.get("part_number")
        required_quantity = args.get("quantity", 1)
        
        availability = await check_inventory(part_number)
        
        return format_availability_report(availability, required_quantity)
```

## Getting Started

### Prerequisites:
```bash
# Required packages
pip install neuro-san>=0.5.40
pip install aiohttp
pip install python-dotenv
```

### Environment Setup:
```bash
# API Keys
export OPENAI_API_KEY="your-key-here"
export ANTHROPIC_API_KEY="your-key-here"  # If using Claude

# Manufacturing Systems
export MES_API_ENDPOINT="https://mes.company.com/api"
export ERP_API_KEY="your-erp-key"

# Customer Systems
export CRM_API_ENDPOINT="https://crm.company.com/api"
export DEALER_PORTAL_KEY="your-portal-key"
```

### Quick Start:
```bash
# Clone the repository
git clone https://github.com/cognizant-ai-lab/neuro-san-studio.git
cd neuro-san-studio

# Install dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

# Copy automotive configuration
cp examples/automotive_ops_and_customer_service/config.hocon registries/

# Start the service
python -m run
```

### Test Queries:
